WaitGroup

Chờ một nhóm goroutine hoàn thành mà không dùng sleep để đoán timing.

🎯 Backend Engineer🧠 Mental model trước syntax🧪 Có code & diagram

Nội dung

1. Tại sao không Sleep?2. Add Done Wait3. Một ví dụ4. Sai lầm phổ biến5. WaitGroup không truyền lỗiBài trước / tiếp theo

1. Tại sao không dùng Sleep để chờ?

Sleep đoán thời gian. WaitGroup diễn đạt đúng ý định: chờ một nhóm công việc hoàn thành.

2. Ba thao tác: Add, Done, Wait

Govar wg sync.WaitGroup

wg.Add(1)
go func() {
    defer wg.Done()
    work()
}()

wg.Wait()

3. Chờ nhiều goroutine

Gofor _, item := range items {
    item := item
    wg.Add(1)
    go func() {
        defer wg.Done()
        process(item)
    }()
}
wg.Wait()

4. Sai lầm phổ biến

Hãy gọi Add trước khi goroutine bắt đầu để tránh race giữa Add và Wait. Và luôn đảm bảo mỗi Add(1) có đúng một Done().

5. WaitGroup không truyền lỗi

Quan trọngWaitGroup chỉ chờ. Nếu concurrent tasks có thể lỗi và bạn muốn cancel các task còn lại, hãy xem errgroup ở bài Error Propagation.
