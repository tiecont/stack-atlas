# Season 04 — Networking with Go

Static HTML course, designed to sit next to `season-03-concurrency`.

## Open

Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Lessons

01. Network Mental Model cho Backend Engineer
02. TCP: Connection, Byte Stream và Framing
03. Viết TCP Server bằng package net
04. UDP và Datagram: Khi không có Connection
05. DNS: Trước TCP còn có bước tìm IP
06. HTTP trên Wire: Request, Response và Connection
07. Xây HTTP Server Production bằng net/http
08. Handler, Middleware và Request Context
09. HTTP Client, Transport và Connection Pooling
10. Timeout, Deadline và Cancellation
11. TLS và HTTPS cho Go Backend
12. HTTP/2: Multiplexing và Connection Behavior
13. Streaming, SSE và WebSocket
14. Reverse Proxy và API Gateway bằng Go
15. gRPC + Network Debugging: Bài tốt nghiệp Season 04

## Notes

- All navigation is relative; the folder can be moved or deployed as-is.
- Diagrams are inline SVG; no external image assets are required.
- HTTP/2 notes reflect the Go 1.27 standard-library documentation current in September 2026.
