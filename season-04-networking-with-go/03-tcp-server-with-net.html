Viết TCP Server bằng package net

Tự tay Listen, Accept, Dial và xử lý connection để hiểu net/http đang che giấu những gì.

Trước khi dùng net/http, hãy tự viết một TCP server nhỏ. Chỉ vài chục dòng code nhưng nó làm rõ listener, connection lifecycle, goroutine-per-connection và deadline.

1. Listener và Accept loop

gopackage main

import (
    "bufio"
    "fmt"
    "log"
    "net"
    "strings"
    "time"
)

func main() {
    ln, err := net.Listen("tcp", ":9000")
    if err != nil { log.Fatal(err) }
    defer ln.Close()

    for {
        conn, err := ln.Accept()
        if err != nil {
            log.Println("accept:", err)
            continue
        }
        go handle(conn)
    }
}

func handle(conn net.Conn) {
    defer conn.Close()
    _ = conn.SetDeadline(time.Now().Add(30 * time.Second))

    line, err := bufio.NewReader(conn).ReadString('\n')
    if err != nil { return }

    fmt.Fprintf(conn, "echo: %s", strings.TrimSpace(line))
}

Mỗi lần Accept trả về một net.Conn. Ta chuyển connection sang goroutine riêng để accept loop có thể quay lại nhận client khác.

2. Không để connection chờ vô hạn

net.Conn có SetDeadline, SetReadDeadline và SetWriteDeadline. Deadline là thời điểm tuyệt đối; sau khi đặt, nó tiếp tục áp dụng cho các I/O sau cho tới khi được thay đổi.

godeadline := time.Now().Add(5 * time.Second)
