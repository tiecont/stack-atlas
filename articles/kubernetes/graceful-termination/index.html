SIGTERM và Graceful Termination

Điều gì xảy ra với request khi Kubernetes terminate pod?

Kubernetes
On this pageLifecycleGo serverGoal
Part of Golang Backend EngineeringKubernetes · Lesson 08

Lifecycle

Pod termination
  |
SIGTERM
  |
mark unready / traffic drains
  |
finish in-flight requests
  |
shutdown before grace period ends

Go server

ctx, stop := signal.NotifyContext(
    context.Background(),
    syscall.SIGTERM,
)
defer stop()
<-ctx.Done()

shutdownCtx, cancel := context.WithTimeout(context.Background(), 20*time.Second)
defer cancel()
_ = server.Shutdown(shutdownCtx)

Goal

Không drop request chỉ vì rollout hoặc scale down.
