Ba loại

Server streaming: request -> many responses
Client streaming: many requests -> response
Bidi streaming: many <-> many

Use cases

  • event feed
  • large upload
  • telemetry
  • interactive session

Backpressure

Streaming không loại bỏ backpressure; sender vẫn cần tôn trọng khả năng đọc của peer.
