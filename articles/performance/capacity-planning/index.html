Capacity Planning

Từ benchmark tới số instance và headroom production.

Performance
On this pageVí dụHeadroomCost
Part of Golang Backend EngineeringPerformance Engineering · Lesson 13

Ví dụ

1 instance sustainable = 4k rps at target p99
target = 100k rps
raw = 25 instances
at 60% target utilization -> ~42 instances
+ failure/headroom

Headroom

  • traffic burst
  • rolling deploy
  • AZ loss
  • dependency degradation
  • GC variation

Cost

Capacity plan phải cân bằng performance, resilience và cost thay vì chỉ chạy ở utilization cực thấp.
