Bounded concurrency

jobs -> 32 workers -> downstream capacity
not
jobs -> 100,000 goroutines -> downstream collapse

Tune by bottleneck

CPU-bound thường gần số core; I/O-bound có thể cao hơn nhưng vẫn bị giới hạn bởi DB, network hoặc remote quota.

Metric

Quan sát queue time, active workers, downstream saturation và tail latency khi tăng concurrency.
