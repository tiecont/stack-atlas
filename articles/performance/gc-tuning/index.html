Garbage Collector và GOMEMLIMIT

Tuning GC khi allocation và memory budget thực sự là bottleneck.

Performance
On this pageTrade-offMemory limitMeasure
Part of Golang Backend EngineeringPerformance Engineering · Lesson 09

Trade-off

More frequent GC -> lower heap, more CPU
Less frequent GC -> larger heap, less GC CPU

Memory limit

Memory limit giúp runtime điều chỉnh GC theo budget process, nhưng không thay thế việc sửa memory leak hoặc unbounded cache.

Measure

Theo dõi GC CPU, heap growth, allocation rate và pause/tail latency.
