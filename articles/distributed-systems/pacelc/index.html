Ngay cả ngày bình thường, consistency thường đổi lấy latency. Bài viết ưu tiên mental model, failure mode và cách áp dụng vào production thay vì chỉ nhớ thuật ngữ.

P-A/C, Else L/C

PACELC mở rộng góc nhìn: nếu Partition thì Availability hay Consistency; Else, khi hệ thống bình thường, ưu tiên Latency hay Consistency.

Cross-region write

Sync replicate Singapore ↔ US trước ACK tăng durability/consistency nhưng write latency chịu speed-of-light + network tail.

Local-first

Acknowledge local rồi async replicate giảm latency nhưng tăng window dữ liệu chưa xuất hiện/được bảo vệ ở region khác.

Design question

Hỏi “request này có cần coordinate với remote region trên critical path không?” thường hữu ích hơn tranh luận abstract về CAP.

Điểm cần nhớ

  • Không partition vẫn có latency/consistency trade-off.
  • Geography là architecture constraint.
  • Critical-path coordination quyết định latency floor.
