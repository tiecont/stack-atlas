Transactional Outbox

Ghi business data và event vào cùng một local database transaction.

Distributed Systems

Pattern

BEGIN
  INSERT orders
  INSERT outbox_event
COMMIT
      |
Outbox Publisher -> Kafka

Schema

create table outbox_events (
  id uuid primary key,
  topic text not null,
  payload jsonb not null,
  published_at timestamptz
);

Điểm mạnh

DB đảm bảo order và outbox row commit cùng nhau. Publisher có thể retry tới khi publish thành công.
