Local Cache vs Redis

So sánh cache trong memory của process với distributed cache dùng chung giữa nhiều instances.

Local cache cực nhanh vì không có network hop. Redis chậm hơn local memory nhưng cho nhiều application instances nhìn thấy cùng một keyspace. Chọn sai tầng cache có thể làm consistency phức tạp hơn cả query gốc.

1. Local cache

gotype Cache struct {
    mu sync.RWMutex
    m  map[string]Entry
}

Ưu điểm: latency rất thấp, không phụ thuộc network. Nhược điểm: mỗi pod có một copy khác nhau và dữ liệu mất khi process restart.

2. Redis cache

Redis chạy như một service riêng. Nhiều Go instances có thể đọc cùng keyspace và TTL được quản lý tập trung.

3. Multi-instance inconsistency

4. Khi nào dùng gì?

Local cache phù hợp data nhỏ, immutable/slow-changing hoặc optimization best-effort. Redis phù hợp shared state, distributed rate limit, shared cache và coordination có semantics rõ.

Điểm cần nhớ

  • Local cache nhanh nhất nhưng fragmented theo process.
  • Redis thêm network hop đổi lấy shared cache.
  • Có thể dùng multi-level cache nhưng complexity tăng.
