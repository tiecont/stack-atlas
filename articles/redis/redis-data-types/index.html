Part of Golang Backend EngineeringRedis & Caching · Lesson 03

Redis không chỉ là key → string. Data structure là một phần của design. Chọn đúng type giúp operation atomic hơn và tránh read-modify-write không cần thiết.

1. Strings

Phù hợp cache JSON/blob, counter và token đơn giản. Các lệnh increment có thể atomic ở Redis server.

2. Hashes

Hữu ích khi một entity có nhiều fields cần đọc/ghi riêng. Nhưng đừng map toàn bộ relational model sang Redis chỉ vì có Hash.

  • Key design và TTL quan trọng ngang serialization.
