Indexes: từ B-tree đến Composite Index

Index tăng tốc access pattern cụ thể nhưng làm write tốn hơn và chiếm storage.

Part of Golang Backend EngineeringPostgreSQL with Go · Lesson 09

“Thêm index” không phải phép thuật. Index hữu ích khi match predicate/order/join pattern. Sai index có thể không được planner dùng hoặc chỉ tăng write amplification.

1. B-tree default

Phù hợp equality và range trên ordered values. Đây là index bạn gặp nhiều nhất.

2. Composite index

Thứ tự columns quan trọng. Index (status, created_at) khác (created_at, status) về access patterns.

3. Partial index

sqlCREATE INDEX jobs_open_created_idx
ON jobs (created_at DESC)
WHERE status = 'open';

4. Index cost

Mỗi insert/update có thể phải cập nhật index liên quan. Hãy giữ indexes phục vụ workload thật.

RuleIndex query pattern, không index tất cả columns.

Điểm cần nhớ

  • Index phục vụ query pattern.
  • Composite order quan trọng.
  • Index tăng write/storage cost.
Bài tập thực hànhĐề xuất index cho query jobs WHERE company_id=? AND status=? ORDER BY created_at DESC LIMIT 50.
