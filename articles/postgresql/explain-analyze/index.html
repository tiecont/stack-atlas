EXPLAIN và EXPLAIN ANALYZE

Đọc planner thay vì đoán: scan type, row estimates, loops, sort và actual timing.

Tuning SQL tốt bắt đầu bằng execution plan. Query text giống nhau có thể chạy rất khác tùy data distribution và statistics.

1. EXPLAIN

Cho estimated plan mà không chạy query. Hữu ích khi query có side effect hoặc rất đắt.

2. EXPLAIN ANALYZE

sqlEXPLAIN (ANALYZE, BUFFERS)
SELECT id, title
FROM jobs
WHERE company_id = 42
ORDER BY created_at DESC
LIMIT 50;

3. Estimated vs actual rows

Chênh lệch lớn có thể chỉ ra statistics không phù hợp hoặc correlation/data distribution đặc biệt.

4. Đừng chỉ nhìn total time

Loops, buffers, sort method, rows removed và scan type cho biết vì sao query tốn.

SafetyEXPLAIN ANALYZE thực sự chạy statement. Cẩn thận với UPDATE/DELETE/INSERT.

Điểm cần nhớ

  • Đo plan trước khi đoán index.
  • Estimated-vs-actual rows là signal quan trọng.
  • ANALYZE thực thi query.
