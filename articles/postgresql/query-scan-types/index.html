Query, Scan và Type Mapping

Viết SQL explicit, scan an toàn và xử lý NULL mà không để mapping lỗi lan ra domain.

Part of Golang Backend EngineeringPostgreSQL with Go · Lesson 04

Phần lớn database code là boundary mapping: row PostgreSQL thành Go type. Boundary rõ giúp SQL vẫn mạnh mà domain không phụ thuộc database representation.

1. QueryRow vs Query

Dùng QueryRow khi kỳ vọng tối đa một row; Query cho stream nhiều rows và luôn đóng rows.

2. Scan explicit

govar u User
err := db.QueryRowContext(ctx, `
    SELECT id, email, created_at
    FROM users WHERE id = $1
`, id).Scan(&u.ID, &u.Email, &u.CreatedAt)

3. NULL

Có thể dùng sql.NullString, pointers hoặc pgtype tùy boundary. Domain type không nhất thiết phải mang database nullable wrappers.

4. Parameterization

Dùng placeholders cho values. Không concatenate user input vào SQL string.

SQL injectionParameterized values bảo vệ dữ liệu. Dynamic identifiers như sort column cần allowlist riêng.

Điểm cần nhớ

  • Scan là schema boundary.
  • NULL cần mapping rõ.
  • Parameterize values; allowlist identifiers.
