pgx: Native PostgreSQL Driver

Part of Golang Backend EngineeringPostgreSQL with Go · Lesson 03

pgx là lựa chọn phổ biến cho Go + PostgreSQL vì cung cấp native PostgreSQL interface và pool riêng, đồng thời hỗ trợ database/sql adapter.

1. pgxpool

gopool, err := pgxpool.New(ctx, dsn)
if err != nil { return err }
defer pool.Close()

var n int
err = pool.QueryRow(ctx, "select 42").Scan(&n)

2. Context ở mọi query

Query cần nhận request context để deadline/cancellation propagate đến database operation.

3. PostgreSQL-specific features

pgx hỗ trợ tốt COPY, notifications, custom types và native protocol capabilities. Chọn abstraction dựa trên nhu cầu, không theo trend.

4. Pool vẫn cần sizing

pgxpool không loại bỏ bài toán capacity. Nó chỉ cung cấp pool implementation phù hợp pgx.

AbstractionDriver choice ít quan trọng hơn query design, transaction correctness và pool discipline.

Điểm cần nhớ

  • pgx là driver/toolkit, không thay SQL knowledge.
  • Context phải đi vào query.
  • Pool sizing vẫn là capacity planning.
Bài tập thực hànhViết cùng một query bằng database/sql và pgxpool, so sánh API surface bạn cần.
