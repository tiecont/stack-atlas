Pagination ở PostgreSQL: Offset vs Keyset

Biến API cursor thành query có index và stable ordering.

Season 05 đã thiết kế cursor contract. Bây giờ ta nối nó với SQL để tránh OFFSET sâu và giữ ordering ổn định.

1. Offset

LIMIT 50 OFFSET 500000 có thể buộc DB đi qua rất nhiều rows trước khi bỏ chúng.

2. Keyset query

sqlSELECT id, title, created_at
FROM jobs
WHERE (created_at, id) < ($1, $2)
ORDER BY created_at DESC, id DESC
LIMIT 50;

3. Index match

Index trên (created_at DESC, id DESC) giúp planner phục vụ order + seek pattern hiệu quả.

4. Cursor opaque

API có thể encode tuple thành opaque cursor để client không phụ thuộc internal schema.

Điểm cần nhớ

  • Keyset pagination seek theo last key.
  • Tie-breaker tạo total order.
  • Index phải match order.
