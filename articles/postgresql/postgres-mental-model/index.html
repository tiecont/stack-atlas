Part of Golang Backend EngineeringPostgreSQL with Go · Lesson 01

Go code không “nói chuyện với database” một cách trừu tượng. Nó dùng connection qua driver/protocol; PostgreSQL parse, plan, execute rồi đọc/write pages và WAL. Mental model này giúp bạn biết bottleneck nằm ở đâu.

1. Query path

2. Database là shared resource

1000 goroutine không có nghĩa bạn nên mở 1000 DB connections. PostgreSQL connection có cost và database thường là bottleneck shared giữa nhiều service.

3. Correctness trước performance

Constraint, transaction và isolation bảo vệ invariant. Index và query tuning chỉ có ý nghĩa sau khi semantics đúng.

4. Measure at database boundary

Latency của query, rows scanned, lock wait, pool wait và transaction duration là những signal khác nhau.

Điểm cần nhớ

  • Pool không làm DB capacity vô hạn.
  • Transaction semantics quan trọng hơn ORM choice.
  • Đo query và pool riêng.
