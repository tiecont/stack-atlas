JSONB, Arrays và PostgreSQL Types

Dùng type mạnh của PostgreSQL đúng chỗ mà không biến relational model thành document dump.

PostgreSQL hỗ trợ JSONB, arrays, UUID, enum-like constraints và nhiều types mạnh. Nhưng flexible type không thay data modeling.

1. JSONB phù hợp metadata biến đổi

Dùng khi shape thay đổi hoặc dữ liệu phụ không cần relational constraint sâu. Core fields cần query/join thường nên là columns rõ.

2. Index JSONB có trade-off

GIN index có thể giúp query containment/path, nhưng index lớn và write cost cao hơn.

3. Arrays

Arrays tiện cho small bounded attributes; relationship giữa entities thường vẫn phù hợp join table hơn.

4. Go mapping

Driver mapping và custom scan/value logic nên nằm ở persistence boundary.

Điểm cần nhớ

  • JSONB là công cụ, không escape hatch khỏi schema.
  • Index flexible types có cost.
  • Keep domain model intentional.
