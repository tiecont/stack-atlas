*sql.DB không phải một connection. Nó là concurrency-safe handle quản lý pool connections. Đây là một trong những mental model quan trọng nhất của Go database programming.

1. Open không đồng nghĩa connect ngay

godb, err := sql.Open("pgx", dsn)
if err != nil { return err }
if err := db.PingContext(ctx); err != nil { return err }

2. Pool knobs

godb.SetMaxOpenConns(50)
db.SetMaxIdleConns(25)
db.SetConnMaxLifetime(30 * time.Minute)
db.SetConnMaxIdleTime(5 * time.Minute)

4. Stats là observability

db.Stats() cho biết OpenConnections, InUse, Idle, WaitCount và WaitDuration. Pool wait tăng là signal cực hữu ích.

Điểm cần nhớ

  • *sql.DB là pool handle.
  • Pool size là backpressure control.
  • Theo dõi WaitCount/WaitDuration.
Bài tập thực hànhLoad test endpoint với MaxOpenConns = 5, 20, 100 và so sánh latency + DB CPU.
