SSRF

User URL -> Backend fetcher -> internal metadata/admin service

Mitigation

  • allow-list destination
  • resolve/check IP ranges
  • block loopback/link-local/private ranges khi không cần
  • limit redirects
  • timeout/body-size limit

Path traversal

Không nối trực tiếp user path vào filesystem path mà không normalize và enforce root boundary.
