Vì sao timeout bắt buộc

Mỗi call giữ connection, goroutine, memory và đôi khi lock. Timeout biến wait vô hạn thành failure có giới hạn.

Timeout budget

Client budget: 1000ms
  API: 900ms
    DB: 250ms
    Cache: 100ms
    Payment: 400ms
    Reserve: 150ms

Timeout downstream nên nhỏ hơn deadline upstream để còn thời gian cleanup và trả response.

Go example

ctx, cancel := context.WithTimeout(r.Context(), 300*time.Millisecond)
defer cancel()

row := db.QueryRowContext(ctx, `select name from users where id=$1`, id)
