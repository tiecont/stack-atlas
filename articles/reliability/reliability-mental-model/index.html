Failure là trạng thái bình thường

Network chậm, dependency timeout, process restart và traffic burst đều là chuyện bình thường. Reliability engineering bắt đầu bằng việc xem failure là thứ phải thiết kế trước.

Request -> API -> DB -> Cache -> Payment
             X       X       X
Một lỗi downstream có thể lan ngược thành cascading failure.

Mục tiêu thực tế

Không loại bỏ mọi failure; hãy giới hạn blast radius, fail nhanh khi cần và phục hồi có kiểm soát.

Ba câu hỏi

  • Failure xảy ra ở đâu?
  • Failure lan truyền bằng cơ chế nào?
  • Hệ thống giảm tải và phục hồi ra sao?
