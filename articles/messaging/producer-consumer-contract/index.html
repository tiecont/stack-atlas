Producer, Consumer và Message Contract

Thiết kế message như public contract: schema, key, metadata, version và semantic meaning.

Part of Golang Backend EngineeringMessaging · Lesson 03

Một message sống lâu hơn function call. Nó có thể nằm trong broker vài giờ, được replay sau nhiều tháng hoặc được consume bởi service deploy ở phiên bản khác.

1. Event vs command

Command thường diễn đạt ý định: SendWelcomeEmail. Event mô tả fact đã xảy ra: UserRegistered.

2. Envelope

gotype Event struct {
    ID          string
    Type        string
    Version     int
    OccurredAt  time.Time
    TraceID     string
    Payload     json.RawMessage
}

3. Backward compatibility

Consumer cũ và mới có thể cùng chạy. Thêm field optional thường dễ hơn đổi meaning hoặc remove field.

4. Event ID

Stable unique event ID hữu ích cho deduplication, tracing và audit.

Điểm cần nhớ

  • Message schema là API contract.
  • Event name mô tả fact, command mô tả intent.
  • Thiết kế evolution ngay từ đầu.
