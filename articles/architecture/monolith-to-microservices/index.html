Monolith, Modular Monolith và Microservices

Microservices không phải điểm xuất phát mặc định.

Architecture
On this pageBa mô hìnhĐiểm cốt lõiKhi chưa nên tách
Part of Golang Backend EngineeringMicroservices Architecture · Lesson 01

Ba mô hình

Monolith
  [ one deployable ]

Modular Monolith
  [ user | order | payment ]

Microservices
  user svc   order svc   payment svc
     |          |            |
   own DB     own DB       own DB

Điểm cốt lõi

Microservices đổi local function call thành network call và đổi một deployment thành nhiều failure domain.

Khi chưa nên tách

Nếu team nhỏ, domain chưa ổn định và deployment monolith chưa phải bottleneck, modular monolith thường rẻ hơn về độ phức tạp.
