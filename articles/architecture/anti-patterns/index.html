Microservices Anti-patterns

Distributed monolith là trạng thái tệ nhất: phức tạp như microservices nhưng coupling như monolith.

Dấu hiệu

  • deploy service A phải deploy B
  • request fan-out quá nhiều
  • shared database
  • transaction xuyên nhiều service cho mọi flow
  • service quá nhỏ chỉ wrap một table

Chatty architecture

API -> A -> B -> C -> D -> E
mỗi hop thêm latency + failure probability

Sửa

Gộp boundary quá nhỏ, đưa invariant về đúng owner và dùng async projection cho read model khi phù hợp.
