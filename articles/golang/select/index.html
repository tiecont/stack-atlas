1. Select là gì?

select giống một switch dành cho channel operations: case nào sẵn sàng thì case đó chạy.

Goselect {
case job := <-jobs:
    process(job)
case <-done:
    return
}

2. Chờ nhiều channel

Nếu nhiều case cùng sẵn sàng, runtime chọn một case pseudo-random để tránh luôn ưu tiên một phía.

3. Timeout

Goselect {
case result := <-resultCh:
    use(result)
case <-time.After(2 * time.Second):
    return errors.New("timeout")
}

4. default tạo non-blocking select

Goselect {
case ch <- value:
    // sent
default:
    // channel chưa sẵn sàng, không chờ
}

Dùng cẩn thận: default trong loop có thể biến code thành busy-spin.

5. Nil channel

Send/receive trên nil channel sẽ block mãi. Trong select, nil channel có thể được dùng để tạm “disable” một case, nhưng cần hiểu rõ để tránh leak/deadlock.
