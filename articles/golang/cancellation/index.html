1. Cancellation tiết kiệm tài nguyên

Khi kết quả không còn cần thiết, tiếp tục compute, query DB hay gọi API chỉ tạo tải vô ích.

2. Lắng nghe ctx.Done()

Gofor {
    select {
    case <-ctx.Done():
        return ctx.Err()
    case job := <-jobs:
        process(job)
    }
}

3. Context tạo thành cây

Cancel parent context sẽ cancel tất cả child context của nó. Đây là cách một request dừng cả những goroutine phụ thuộc.

4. Cleanup vẫn cần defer

Cancellation không tự đóng file, release semaphore hay rollback state của bạn. Hãy dùng defer để cleanup resource local.

5. Cancellation là cooperative

Quan trọngGo không “kill” goroutine tùy ý. Goroutine phải tự quan sát tín hiệu cancellation và return ở điểm phù hợp.
