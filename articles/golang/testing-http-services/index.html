Go có httptest rất mạnh. HTTP test tốt tập trung vào contract: status, headers, body, side effects và cancellation.

1. Handler test bằng httptest

goreq := httptest.NewRequest(http.MethodGet, "/users/42", nil)
rr := httptest.NewRecorder()

handler.ServeHTTP(rr, req)

if rr.Code != http.StatusOK { t.Fatalf("got %d", rr.Code) }

2. Test dependency failure

Stub repository/service để ép not-found, timeout, conflict và internal failure. Test error mapping ở boundary.

3. Real server khi cần network behavior

httptest.NewServer hữu ích khi test client behavior, redirect, headers hoặc integration qua real TCP listener.

4. Race detector

HTTP handlers chạy concurrent, vì vậy test suite nên có lúc chạy với go test -race ./....

Đừng overmockNếu test mock mọi function call order, refactor vô hại cũng phá test. Ưu tiên observable behavior.

Điểm cần nhớ

  • httptest đủ cho phần lớn HTTP boundary tests.
  • Test failures chứ không chỉ happy path.
  • Race detector là công cụ quan trọng cho server code.
