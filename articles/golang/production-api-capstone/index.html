3. Request path

Request ID → auth → validation → service → repository → response mapping. Context deadline và cancellation đi xuyên suốt path.

4. Production checklist

  • Explicit server/client timeouts.
  • Bounded body và concurrency.
  • Stable error contract.
  • Graceful shutdown.
  • Readiness/liveness.
  • Structured logs + metrics hooks.
  • Tests cho happy path và failure path.

Điểm cần nhớ

  • Production server là một lifecycle, không phải vài routes.
  • Boundary rõ làm reliability dễ kiểm soát.
  • Đừng tối ưu framework trước khi đo bottleneck.
