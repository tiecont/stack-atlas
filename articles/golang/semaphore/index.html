1. Semaphore dùng để làm gì?

Semaphore giới hạn bao nhiêu công việc được phép ở trong một vùng concurrent cùng lúc.

2. Dùng buffered channel làm semaphore

Gosem := make(chan struct{}, 20)

    defer func() { <-sem }()

3. Weighted semaphore

Package golang.org/x/sync/semaphore hỗ trợ weighted semaphore, hữu ích khi mỗi task có “trọng lượng” tài nguyên khác nhau.

4. Khi semaphore phù hợp

Khi task đã có lifecycle riêng nhưng bạn chỉ cần giới hạn concurrency: outbound HTTP requests, parallel file processing, database-heavy jobs.

5. Worker Pool hay Semaphore?

Khác nhauWorker pool có worker sống lâu và nhận job từ queue. Semaphore không cần worker cố định; nó chỉ kiểm soát số task đang chạy cùng lúc.
