1. Atomic là gì?

Atomic cho phép một số thao tác đọc/ghi/cập nhật nhỏ diễn ra như một đơn vị không bị xen ngang bởi goroutine khác.

Govar count atomic.Int64

count.Add(1)
current := count.Load()

2. Counter là use case dễ hiểu nhất

Metrics nội bộ, sequence nhỏ, flags và counters thường là nơi atomic phù hợp.

Gotype Stats struct {
    requests atomic.Uint64
}

func (s *Stats) Inc() { s.requests.Add(1) }

3. Compare-And-Swap

CAS chỉ cập nhật khi giá trị hiện tại đúng với expected value. Đây là building block của nhiều lock-free algorithm, nhưng đừng vội dùng để thay mutex.

Goif state.CompareAndSwap(old, new) {
    // update thành công
}

4. Giới hạn của Atomic

Atomic rất tốt cho một biến độc lập. Nhưng nếu invariant liên quan nhiều field — ví dụ balance và version phải đổi cùng nhau — mutex thường dễ đúng hơn.

5. Atomic hay Mutex?

Mental modelAtomic tối ưu thao tác nhỏ. Mutex bảo vệ invariant. Nếu bạn phải suy nghĩ quá lâu để chứng minh atomic code đúng, mutex có thể là lựa chọn tốt hơn.
