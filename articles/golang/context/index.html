1. Context giải quyết gì?

Context truyền deadline, cancellation signal và request-scoped metadata xuyên qua call graph.

Gofunc Handle(ctx context.Context) error {
    return service.Do(ctx)
}

2. Deadline và timeout

Goctx, cancel := context.WithTimeout(parent, 2*time.Second)
defer cancel()

err := client.Call(ctx)

3. Cancellation

Khi client disconnect hoặc upstream không còn cần kết quả, context có thể báo cho downstream dừng sớm.

Goselect {
case <-ctx.Done():
    return ctx.Err()
case job := <-jobs:
    return process(job)
}

4. Context Values

Value dành cho request-scoped metadata như trace ID, không phải nơi nhét dependency, config hay optional parameters.

5. Một vài rule quan trọng

ConventionContext thường là parameter đầu tiên, tên ctx; đừng lưu Context vào struct lâu dài; và luôn gọi cancel function khi bạn tạo child context có cancel/timeout.
