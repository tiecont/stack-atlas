Pipeline

1. Pipeline là gì?

Pipeline chia xử lý thành các stage; output của stage trước trở thành input của stage sau.

2. Mỗi stage có contract rõ ràng

Gofunc transform(in <-chan Item) <-chan Item {
    out := make(chan Item)
    go func() {
        defer close(out)
        for item := range in {
            out <- mutate(item)
        }
    }()
    return out
}

3. Backpressure chạy ngược pipeline

Nếu Persist chậm, output channel của Transform đầy, Transform block; rồi input của nó đầy và Read cũng chậm lại. Đây là backpressure tự nhiên.

4. Close đúng phía

Stage tạo ra output channel thường chịu trách nhiệm đóng nó khi không còn gửi thêm dữ liệu.

5. Pipeline production cần cancellation

Mỗi send/receive dài hạn nên cân nhắc select với ctx.Done() để pipeline không bị treo khi request bị hủy.
