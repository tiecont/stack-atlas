Structured Logging và Request Correlation

Log để điều tra production: fields, request ID, latency và error context thay vì printf tự do.

Part of Golang Backend EngineeringProduction HTTP Server · Lesson 13

Ở một request đơn lẻ, print log có vẻ đủ. Khi có hàng trăm instance và hàng triệu request, structured fields mới cho phép query và correlate.

1. Structured fields

gologger.Info("request completed",
    "request_id", requestID,
    "method", r.Method,
    "path", r.URL.Path,
    "status", status,
    "duration_ms", time.Since(start).Milliseconds(),
)

2. Correlation ID

Request ID giúp nối log trong một service. Distributed tracing dùng trace/span IDs để nối qua nhiều service.

3. Không log secrets

Authorization header, password, token, session cookie và sensitive PII không nên xuất hiện trong log mặc định.

4. Log volume là cost

Access log cho mọi request có thể rất lớn. Thiết kế fields, sampling và retention theo mục tiêu điều tra.

Signal > noiseMột log tốt trả lời: request nào, chuyện gì xảy ra, mất bao lâu, lỗi ở boundary nào.

Điểm cần nhớ

  • Log fields thay vì ghép string tùy ý.
  • Correlation IDs giúp điều tra.
  • Không log secret/PII vô tội vạ.
