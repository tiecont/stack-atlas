1. Vì sao không tạo một goroutine cho mọi item?

Goroutine nhẹ nhưng downstream thì không vô hạn. Một triệu goroutine gọi database vẫn có thể làm database chết.

2. Worker Pool

Gofunc worker(jobs <-chan Job) {
    for job := range jobs {
        process(job)
    }
}

for i := 0; i < 20; i++ {
    go worker(jobs)
}

3. Jobs và Results

Gofunc worker(jobs <-chan Job, results chan<- Result) {
    for job := range jobs {
        results <- process(job)
    }
}

4. Sizing worker pool

Đừng chọn worker count chỉ theo CPU. Với I/O-bound workload, số worker còn phụ thuộc connection pool, API quota, latency và mức concurrency downstream cho phép.

5. Shutdown sạch

Producer đóng jobs channel khi hết việc; worker thoát khỏi range; main dùng WaitGroup hoặc errgroup để chờ tất cả kết thúc.
