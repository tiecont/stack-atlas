Trade-off

Distroless/scratch giảm attack surface nhưng debugging shell-based khó hơn. Chọn theo operating model.

Checklist

  • non-root
  • read-only filesystem khi phù hợp
  • CA certificates
  • timezone nếu cần
  • no build tools in runtime image
