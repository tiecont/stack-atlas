Reproducible Build và Version Metadata

Biết binary nào đang chạy và nó được build từ commit nào.

Golang
On this pageVersion varsBuildWhy
Part of Golang Backend EngineeringProduction Go · Lesson 03

Version vars

var version = "dev"
var commit = "unknown"

Build

go build -trimpath   -ldflags "-X main.version=v1.4.2 -X main.commit=abc123"   ./cmd/api

Why

Version metadata giúp incident response, rollback và trace artifact về source.
