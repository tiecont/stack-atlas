List endpoint thường trông vô hại lúc data nhỏ. Khi data lớn, offset sâu, sort không index và filter tùy tiện nhanh chóng trở thành query đắt tiền.

1. Contract của list endpoint

Xác định page size tối đa, allowed sort fields và filter fields thay vì cho client gửi column tùy ý.

2. Offset pagination

Dễ dùng và phù hợp admin UI/page nhỏ, nhưng offset sâu có thể tốn kém và dễ bị duplicate/skip khi data thay đổi liên tục.

3. Cursor pagination

4. Stable ordering

Cursor cần total order ổn định, thường bằng tuple như (created_at, id).

Database connectionPagination design là API + database design cùng lúc. Season 06 sẽ đi sâu index và keyset query.

Điểm cần nhớ

  • Limit mọi list endpoint.
  • Allowlist sort/filter fields.
  • Cursor cần stable ordering và index phù hợp.
