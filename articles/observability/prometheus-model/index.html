Prometheus Mental Model

Time-series metrics, labels và cardinality.

Metric

http_requests_total{
  method="GET",
  route="/users/:id",
  status="200"
}

Cardinality

Label như user_id hoặc request_id có cardinality cực cao và có thể làm metrics backend bùng nổ.

Rule

Metrics dùng label có tập giá trị nhỏ, ổn định. High-cardinality context để logs/traces xử lý.
