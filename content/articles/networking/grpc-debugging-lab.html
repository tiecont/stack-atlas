Bài cuối nối các khái niệm lại: gRPC cho thấy một RPC abstraction vẫn chạy trên network protocol; debugging cho thấy bạn phải nhìn xuyên abstraction khi production có vấn đề.

1. gRPC thay function call bằng network call

Protocol Buffers định nghĩa service contract; code generation tạo client/server stubs. Nhưng gọi client.GetUser(...) vẫn có thể gặp DNS failure, connect timeout, TLS error, deadline exceeded hoặc server unavailable.

2. Contract-first

protosyntax = "proto3";

service UserService {
  rpc GetUser(GetUserRequest) returns (User);
}

message GetUserRequest {
  string id = 1;
}

message User {
  string id = 1;
  string name = 2;
}

Generated types giảm ambiguity so với hand-written JSON contract, nhưng versioning vẫn cần compatibility discipline.

3. HTTP client tracing

gotrace := &httptrace.ClientTrace{
    DNSStart: func(info httptrace.DNSStartInfo) {
        log.Println("dns start", info.Host)
    },
    GotConn: func(info httptrace.GotConnInfo) {
        log.Println("reused:", info.Reused)
    },
}

ctx := httptrace.WithClientTrace(context.Background(), trace)
req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
_, _ = client.Do(req)

httptrace giúp tách latency thành DNS/connect/connection reuse/request events thay vì chỉ biết “Do mất 800ms”.

4. httptest: test network behavior không cần service thật

gosrv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
    time.Sleep(100 * time.Millisecond)
    w.WriteHeader(http.StatusOK)
}))
defer srv.Close()

resp, err := client.Get(srv.URL)

httptest.NewTLSServer còn hữu ích khi test TLS client behavior.

5. Toolbox khi production có network issue

  • curl -v: HTTP/TLS/headers nhanh.
  • ss -tnp: TCP sockets trên Linux.
  • dig/getent hosts: DNS.
  • openssl s_client: certificate/TLS inspection.
  • tcpdump/Wireshark: packet-level khi cần đi sâu.
  • httptrace: phase timing ngay trong Go client.
  • httptest: reproduce timeout/status/TLS behavior trong tests.

6. Capstone project

Xây một mini gateway bằng Go:

  • HTTP server nhận GET /aggregate/.
  • Gọi hai upstream services concurrent.
  • Reuse một configured http.Client.
  • Request có deadline 800ms và cancel downstream khi client disconnect.
  • Một upstream chạy TLS bằng httptest.NewTLSServer.
  • Gateway log DNS/connect/connection reuse bằng httptrace.
  • Expose một streaming endpoint SSE.
  • Graceful shutdown.
