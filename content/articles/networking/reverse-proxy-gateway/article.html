Reverse proxy nhận HTTP request từ client, tạo outbound request tới backend rồi chuyển response trở lại. Go có net/http/httputil.ReverseProxy để xây proxy behavior mà không cần tự copy mọi chi tiết HTTP.

1. ReverseProxy với Rewrite

gotarget, _ := url.Parse("http://127.0.0.1:9000")
proxy := &httputil.ReverseProxy{
    Rewrite: func(pr *httputil.ProxyRequest) {
        pr.SetURL(target)
        pr.SetXForwarded()
    },
}

http.ListenAndServe(":8080", proxy)

API hiện đại của ReverseProxy cung cấp Rewrite và ProxyRequest để kiểm soát outbound request rõ hơn.

2. Forwarding headers là trust boundary

X-Forwarded-For, X-Forwarded-Proto và host information thường được dùng để giữ metadata qua proxy. Nhưng bạn phải biết proxy nào đáng tin, vì client cũng có thể tự gửi header nếu edge không sanitize.

3. Gateway nên làm gì?

  • Routing và protocol boundary.
  • Authentication ở edge khi phù hợp.
  • Rate limit / quota.
  • Tracing/request ID.
  • Timeout và upstream policy.
Đừng nhét business logic vào gatewayNếu gateway trở thành nơi chứa mọi rule domain, nó nhanh chóng trở thành distributed monolith ở edge.

4. Proxy cũng cần resilience

Upstream timeout, connection pool, retry, body streaming và client cancellation đều ảnh hưởng proxy behavior. Một proxy đơn giản trong lab khác rất xa gateway production chịu hàng chục nghìn RPS.
