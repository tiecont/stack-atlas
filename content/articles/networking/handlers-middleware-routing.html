Một HTTP backend Go tốt thường là pipeline của http.Handler. Middleware chỉ là function nhận handler và trả về handler mới.

1. Handler là interface rất nhỏ

gotype Handler interface {
    ServeHTTP(ResponseWriter, *Request)
}

Sự đơn giản này cho phép router, auth, logging, metrics và business handler compose với nhau.

2. Middleware chain

gofunc logging(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()
        next.ServeHTTP(w, r)
        log.Printf("%s %s %s", r.Method, r.URL.Path, time.Since(start))
    })
}

3. Request context là lifecycle signal

r.Context() bị cancel khi request bị hủy hoặc server-side lifecycle kết thúc phù hợp. Hãy truyền nó xuống DB/HTTP call thay vì tạo context.Background() giữa request path.

gofunc handle(w http.ResponseWriter, r *http.Request) {
    user, err := repo.FindUser(r.Context(), r.PathValue("id"))
    // ...
}
Context không phải túi đựng dependencyDùng context cho cancellation, deadline và request-scoped metadata nhỏ. Đừng nhét database client hay service container vào context.

4. Middleware nào nên có?

  • Request ID / tracing.
  • Authentication / authorization boundary phù hợp.
  • Access log và metrics.
  • Recovery ở process boundary.
  • Rate limit nếu thuộc trách nhiệm service.
