net/http đủ mạnh để xây nhiều backend service mà không cần framework. Học nó trước giúp bạn biết framework đang thêm ergonomics gì và runtime behavior nào vẫn thuộc standard library.

1. ServeMux và route hiện đại

Từ Go 1.22, ServeMux hỗ trợ method matching và wildcard path patterns. Bạn có thể viết route khá rõ ràng chỉ với standard library.

gomux := http.NewServeMux()

mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id")
    fmt.Fprintf(w, "user=%s", id)
})

2. Dùng http.Server thay vì chỉ gọi helper mặc định

gosrv := &http.Server{
    Addr:              ":8080",
    Handler:           mux,
    ReadHeaderTimeout: 5 * time.Second,
    IdleTimeout:       60 * time.Second,
}

if err := srv.ListenAndServe(); err != nil && err != http.ErrServerClosed {
    log.Fatal(err)
}

Server production cần policy về thời gian chờ và lifecycle. Không nên coi default là thiết kế đầy đủ cho mọi workload.

3. Handler chạy concurrent

net/http phục vụ các connection/request concurrently. Điều này có nghĩa mọi shared state mà handler truy cập phải an toàn cho concurrent access.

4. Graceful shutdown

goctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()

if err := srv.Shutdown(ctx); err != nil {
    log.Printf("shutdown: %v", err)
}

Shutdown cho server cơ hội dừng nhận công việc mới và chờ active connections phù hợp thay vì kill process thô bạo.
