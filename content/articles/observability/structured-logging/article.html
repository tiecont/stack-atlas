JSON log

logger.Info("payment failed",
    "order_id", orderID,
    "user_id", userID,

)

Context cần có

  • request id
  • trace id
  • service/version
  • tenant/user khi phù hợp
  • error classification
  • latency hoặc operation

Anti-pattern

Log một câu text dài không cấu trúc làm search, aggregation và alert khó hơn.
