Transaction biến nhiều statements thành một unit theo isolation semantics. Nhưng transaction dài giữ connection và có thể giữ locks/version state lâu hơn cần thiết.

1. Pattern cơ bản

gotx, err := db.BeginTx(ctx, nil)
if err != nil { return err }
defer tx.Rollback()

// queries through tx

return tx.Commit()

2. Chỉ query qua tx

Sau BeginTx, statements thuộc transaction phải đi qua tx, không gọi nhầm db giữa workflow.

3. Không gọi network lâu trong transaction

Gọi HTTP/Kafka trong lúc giữ transaction mở có thể kéo dài lock và làm pool cạn. Outbox pattern thường giải bài toán publish sau commit.

4. Business invariant

Transaction boundary nên bao quanh invariant cần atomicity, không phải bao quanh toàn bộ handler.

RuleTransaction càng dài, contention càng dễ tăng.

Điểm cần nhớ

  • Rollback defer là safety net.
  • Transaction scope theo invariant.
  • Tránh external network call trong transaction.
