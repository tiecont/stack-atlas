SQL injection thường xuất hiện khi data được trộn vào query string. Prepared/parameterized queries giữ code SQL và values tách biệt.

1. Placeholders

gorow := db.QueryRowContext(ctx,
    "SELECT id FROM users WHERE email = $1",
    email,
)

2. Dynamic ORDER BY

Placeholder không đại diện cho identifier. Sort field phải map từ allowlist sang SQL fragment do server kiểm soát.

3. Prepared statement lifecycle

Explicit prepare hữu ích trong một số workload, nhưng driver/protocol có thể đã tối ưu. Đo trước khi tạo statement cache phức tạp.

4. Least privilege

App database role chỉ nên có quyền cần thiết; migration role có thể tách riêng.

SecurityParameterized query là baseline, không phải toàn bộ database security.

Điểm cần nhớ

  • Values dùng parameters.
  • Identifiers dùng allowlist.
  • DB role theo least privilege.
