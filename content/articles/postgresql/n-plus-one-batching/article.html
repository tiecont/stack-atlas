N+1 thường không xuất hiện trong unit test với 3 rows. Nó bùng nổ khi endpoint trả 100 items và mỗi item gọi thêm một query.

1. N+1 pattern

gojobs := repo.ListJobs(ctx)
for _, j := range jobs {
    j.Company = repo.FindCompany(ctx, j.CompanyID) // N queries
}

2. Batch query

Thu company IDs rồi query một lần bằng WHERE id = ANY($1), sau đó map theo ID.

3. JOIN không phải lúc nào cũng tốt nhất

JOIN có thể duplicate rows với one-to-many. Có lúc hai query batched dễ kiểm soát hơn một giant join.

4. Observe query count

Metrics/tracing cho database calls per request giúp phát hiện regression.

HeuristicNếu query nằm trong loop theo số item từ DB, hãy dừng lại và hỏi liệu đây có phải N+1.

Điểm cần nhớ

  • N+1 là round-trip problem.
  • Batching thường giảm latency mạnh.
  • Đếm queries per request.
