sqlc phù hợp khi bạn muốn viết SQL thật và để tool generate type-safe wrappers. Điều quan trọng vẫn là boundary giữa use case và persistence.

1. SQL source of truth

sql-- name: GetUser :one
SELECT id, email, created_at
FROM users
WHERE id = $1;

2. Generated methods

sqlc sinh Go types/methods dựa trên schema/query. Bạn vẫn review execution plan và transaction semantics như SQL bình thường.

3. Repository vừa đủ

Không cần tạo generic IRepository[T] chỉ để che SQL. Interface nên xuất phát từ use case cần gì.

4. Transaction integration

Generated queries thường có thể bind vào transaction handle để workflow dùng cùng transaction.

DesignAbstraction tốt làm business code rõ hơn; abstraction chỉ đổi tên QueryRow thành Get không tạo nhiều giá trị.

Điểm cần nhớ

  • Viết SQL, generate plumbing.
  • Repository interface theo use case.
  • Generated code không thay query tuning.
