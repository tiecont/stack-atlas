Bài cuối Season 06 kết nối mọi thứ: correctness trước, rồi performance, rồi operational behavior. Một persistence layer tốt không chỉ “query được data” mà còn fail có kiểm soát dưới concurrency.

1. Schema

  • Primary keys và constraints rõ.
  • Indexes theo query patterns.
  • Migrations backward-compatible.

2. Runtime database layer

  • Pool có giới hạn.
  • Context/deadline cho queries.
  • Transactions ngắn.
  • Classify conflict/not-found/retryable errors.

3. Performance workflow

4. Operational checklist

  • Pool stats metrics.
  • Query latency histograms.
  • Migration runbook.
  • Backup/restore thuộc infra nhưng app phải hiểu recovery assumptions.
  • Load test với data volume gần production.

Điểm cần nhớ

  • Correctness → observability → performance.
  • Pool, locks và query plan đều ảnh hưởng p99.
  • SQL knowledge là core backend skill.
