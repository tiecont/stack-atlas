Retry không miễn phí

Nếu 10.000 request cùng fail và mỗi request retry 3 lần, downstream có thể nhận thêm hàng chục nghìn request đúng lúc nó yếu nhất.

Backoff

delay := 100 * time.Millisecond
for attempt := 0; attempt < 5; attempt++ {
    if err := call(); err == nil { return nil }
    time.Sleep(delay)
    delay *= 2
}

Jitter

Jitter làm thời điểm retry lệch nhau, giảm thundering herd.

Chỉ retry lỗi có khả năng tạm thời và khi operation có semantics an toàn hoặc idempotent.
