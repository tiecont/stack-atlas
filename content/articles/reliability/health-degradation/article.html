Health semantics

  • Liveness: process còn hoạt động?
  • Readiness: có nên nhận traffic mới?
  • Dependency health: capability nào đang degraded?

Degraded mode

Search down -> API returns basic DB results
Recommendation down -> page still loads
Analytics down -> request still succeeds

Tránh cascade

Không nên làm readiness phụ thuộc mù quáng vào mọi downstream nếu điều đó khiến hàng loạt pod bị rút khỏi traffic chỉ vì một dependency phụ trợ lỗi.
