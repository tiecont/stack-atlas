Bài toán

Xây API gọi Payment + Inventory + Email. Payment là critical path; email async. Hệ thống phải chịu được một dependency chậm mà không collapse.

Kiến trúc

Client
  |
Rate Limit
  |
API -----> Payment (timeout + breaker)
 |  |  \----> Inventory (timeout)
 |
 +-------> Queue -> Email Worker

Checklist

  • deadline propagation
  • bounded concurrency
  • retry + jitter
  • idempotency key
  • load shedding
  • p95/p99
  • queue depth
  • breaker state
  • dependency error rate
