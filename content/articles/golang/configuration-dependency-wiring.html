Production service dễ debug hơn khi dependency graph được tạo rõ ở startup. Global singleton tiện lúc đầu nhưng làm test, lifecycle và ownership khó kiểm soát.

1. Composition root

gofunc main() {
    cfg := mustLoadConfig()
    db := mustOpenDB(cfg.DatabaseURL)
    repo := NewUserRepo(db)
    svc := NewUserService(repo)
    handler := NewHandler(svc)
    runServer(cfg, handler)
}

2. Fail fast với config

Port sai, DSN thiếu, secret rỗng hay timeout âm nên fail ngay lúc startup thay vì đợi request đầu tiên mới phát hiện.

3. Constructor explicit

Constructor nhận interface hoặc concrete dependency cần thiết giúp dependency graph nhìn thấy được bằng code và compiler.

4. Lifecycle ownership

Ai tạo resource thì nên rõ ai đóng nó. DB pool, tracer provider và server đều có shutdown lifecycle.

Design testNếu unit test phải boot cả application chỉ để test một service, dependency boundary có thể đang quá chặt.

Điểm cần nhớ

  • Khởi tạo dependency ở startup.
  • Validate config một lần, sớm.
  • Lifecycle ownership phải rõ.
