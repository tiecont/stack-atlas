1. Mental model

String trong Go là immutable sequence of bytes, thường chứa UTF-8 nhưng type không bắt buộc content hợp lệ UTF-8. `len(s)` đếm bytes, không phải số ký tự người dùng nhìn thấy.

`[]byte` mutable. Conversion giữa string và byte slice có thể tạo allocation/copy tùy context và optimization; hãy đo nếu nằm ở hot path.

Runtime noteNội dung runtime được viết theo Go 1.27 hiện hành. Các chi tiết implementation có thể thay đổi; language/spec behavior mới là contract ổn định.

3. Hiểu sâu hơn

`range` trên string decode UTF-8 thành rune positions/values. Index `s[i]` trả byte. Với protocol/text ASCII-ish, byte operations có thể đúng; với user text, cần Unicode-aware semantics.

`strings.Builder` hoặc `bytes.Buffer` giúp xây output nhiều phần hiệu quả hơn nối string lặp trong hot loop.

Examplevar b strings.Builder
for _, part := range parts { b.WriteString(part) }
out := b.String()

4. Khi đặt vào backend thật

JSON/HTTP headers/IDs thường là bytes/string. Log pipeline hoặc parser có thể tốn allocation vì convert qua lại. Nhưng correctness encoding quan trọng hơn tối ưu; chỉ dùng unsafe zero-copy trick khi thực sự bắt buộc và hiểu lifetime rất sâu.

5. Sai lầm thường gặp & điều cần nhớ

Sai lầm thường gặp

  • `len(string)` như character count.
  • Index byte rồi cắt giữa UTF-8 code point.
  • Convert `string(b)`/`[]byte(s)` hàng loạt trong hot loop mà không đo.

Điều cần mang sang bài tiếp theo

  • String là bytes immutable; Unicode là layer semantics phía trên.
  • Measure conversion/allocation ở hot path.
  • Ưu tiên safe standard APIs trước zero-copy tricks.
