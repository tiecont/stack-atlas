Middleware lý tưởng xử lý cross-cutting concerns. Khi middleware bắt đầu query nhiều bảng và điều phối business workflow, boundary đã bị méo.

1. Middleware là higher-order handler

gotype Middleware func(http.Handler) http.Handler

func Chain(h http.Handler, m ...Middleware) http.Handler {
    for i := len(m)-1; i >= 0; i-- { h = m[i](h) }
    return h
}

2. Order matters

Recovery nên bao ngoài để bắt panic phía trong. Request ID nên có sớm để logs sau đó đều dùng được. Auth phải chạy trước handler cần principal.

3. Context metadata vừa đủ

Request ID, trace context hoặc authenticated principal có thể đi qua context. Dependency container không nên được giấu trong context.

4. Middleware budget

Mỗi middleware thêm work vào mọi request. Một middleware gọi network service có thể trở thành bottleneck toàn hệ thống.

Điểm cần nhớ

  • Middleware dành cho cross-cutting concerns.
  • Thứ tự middleware có semantic.
  • Đừng giấu dependency trong context.
