1. Timeout là một phần của reliability

Không có timeout nghĩa là bạn chấp nhận chờ vô hạn. Trong distributed systems, đó gần như luôn là một assumption nguy hiểm.

2. HTTP client phải có timeout

Goclient := &http.Client{
    Timeout: 2 * time.Second,
}
resp, err := client.Do(req)

3. Database cũng nhận context

Goctx, cancel := context.WithTimeout(ctx, 500*time.Millisecond)
defer cancel()
rows, err := db.QueryContext(ctx, query)

4. Layered timeout

Timeout con nên nhỏ hơn deadline cha. Nếu request có budget 2s, đừng cấp 3s cho database rồi 3s cho API khác.

5. Timer trong loop

Trong hot loop, tạo time.After liên tục có thể tạo nhiều timer allocation. Với code performance-sensitive, cân nhắc time.NewTimer và reset đúng cách.
