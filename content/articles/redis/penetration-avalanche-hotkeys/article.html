Không phải mọi cache incident đều là “Redis chậm”. Có những pattern đến từ miss traffic, expiration pattern hoặc phân phối key không đều.

1. Penetration

Request cho key không tồn tại liên tục đi xuyên cache xuống DB. Negative caching hoặc validation có thể giảm load.

2. Avalanche

Nhiều key expire gần nhau hoặc Redis cluster mất khả dụng làm lượng lớn traffic đổ xuống database.

3. Hot key

Một key nhận phần lớn traffic có thể saturate một Redis shard hoặc network path dù tổng QPS chưa cao.

4. Metrics trước thuật ngữ

ObserveTheo dõi hit ratio, miss rate, origin QPS, command latency, evictions, memory và traffic theo key pattern. Tên pattern chỉ giúp giao tiếp; metrics mới giúp chẩn đoán.

Điểm cần nhớ

  • Negative caching giúp nonexistent-key traffic.
  • Expiration distribution ảnh hưởng avalanche.
  • Hot key là skew problem.
