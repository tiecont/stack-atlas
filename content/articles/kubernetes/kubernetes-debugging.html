Workflow

User error
 -> ingress/service
 -> endpoints
 -> pod readiness
 -> logs/metrics
 -> CPU/memory
 -> dependency connectivity

Common cases

  • CrashLoopBackOff
  • OOMKilled
  • readiness failing
  • DNS failure
  • connection timeout
  • CPU throttling

Mindset

Đừng bắt đầu bằng restart. Trước hết cần biết failure domain và evidence.
